# Isolate memory and reflection at the failure boundary

The primary ablation keeps the initial Proposer identical and prevents it from reading Experience Memory. Failed candidates enter one of four strategies—Regenerate, Reflect, Memory Repair, or Memory + Reflect—so the effects of retrieved experience and explicit Diagnosis can be attributed at the same intervention point. Memory-augmented initial proposal is deferred to a separate experiment; V1 and the V2 adapter control remain system baselines rather than levels of this factor.
