# Add TextWorld as a gated third environment

V2 will retain Karel and MiniGrid in its initial benchmark for controlled comparison with V1, then add a constrained TextWorld pilot to test language grounding and object-oriented task reasoning. The pilot uses a short fixed-vocabulary quest compiled from V2 DSL and becomes a formal benchmark only after Python 3.11, licensing, 100-seed cross-process replay, structured-evidence, and performance gates pass; Craftax and HighwayEnv remain purpose-specific fallbacks rather than automatic replacements.
