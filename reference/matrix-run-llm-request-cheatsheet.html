matrix run 速查表

核心公式： arms × population × (1 + repair cycles) × correction requests

層次目前值作用
arms484 tasks × 3 searches × 4 failures
population1 或 4每個 arm 要找幾個候選
repair cycles1失敗候選可再試幾輪
correction最多 3JSON／DSL 不合法時重問

上限

16 single arms × 6 = 96 +32 population arms × 24 = 768 += 864 requests

三個最值得觀察的欄位

  • model_requests：實際模型請求數。
  • candidate_programs：產生／修復過幾個候選。
  • total_repair_attempts：評估失敗後重試幾次。
